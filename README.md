# Movi Fácil

## Descrição do Projeto

O Movi Fácil é uma plataforma web criada para melhorar a experiência de mobilidade urbana, conectando transporte público, incentivo ao uso coletivo e uma jornada mais simples para os usuários.

## Tecnologias Utilizadas

- React
- Vite
- TypeScript
- TailwindCSS
- React Router DOM
- React Hook Form

## Estrutura de Pastas

```text
Projeto/
├── MoviFacil/
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── vite.config.ts
└── README.md
```

## Como Executar Localmente

1. Clone o repositório do GitHub:

```sh
git clone <url-do-repositorio>
```

2. Entre na pasta do projeto:

```sh
cd MoviFacil
```

3. Instale as dependências:

```sh
npm install
```

4. Inicie o servidor de desenvolvimento:

```sh
npm run dev
```

5. Abra o endereço local exibido no terminal pelo Vite, normalmente:

```text
http://localhost:5173
```
